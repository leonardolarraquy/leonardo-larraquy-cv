# Leonardo Larraquy — Personal CV Site

Static portfolio site for [leonardolarraquy.com.ar](https://www.leonardolarraquy.com.ar/).

Independent from the Cloud Experts business site in `../cloudexperts/`.

## Stack

HTML, CSS, and vanilla JavaScript.

## Structure

```
leonardolarraquy/
  index.html      Main portfolio page
  index2.html     Alternate/test page
  style.css
  script.js
  robots.txt
  sitemap.xml
  iframe.html
  img/            Local images (portrait, certs, work samples)
```

## Deploy

Upload the contents of this folder to the hosting bucket for `leonardolarraquy.com.ar` (e.g. Cloudflare Pages or S3 + CloudFront).

Do **not** mix files with `cloudexperts/` — they are separate sites and separate domains.
